# Code of Conduct

## Standards

Treat everyone with respect, patience, and courtesy. Constructive criticism is
welcome; harassment, threats, discrimination, sexual harassment, spam, and
deliberate disruption are not. Respect others' privacy and do not publish
private information or recordings without permission.

## Profanity and content examples

Streamer Censoring Multitool (SCM) is a streaming safety utility. Relevant
target words or test cases may be quoted for testing or debugging, but must
not be directed at anyone as abuse. Use only the examples necessary, add
content warnings when appropriate, and do not upload identifiable recordings
or webcam captures without consent.

## Scope and enforcement

These standards apply to repository issues, pull requests, discussions, and
other project-managed spaces. Intzevidis7 may remove inappropriate content,
close discussions, or restrict participation, considering severity, context,
and repeated behavior.

## Reporting

Use GitHub's reporting tools to report abusive content. For project moderation,
contact Intzevidis7 through an existing project thread using only
non-sensitive information. Ask for a private channel before sharing private
evidence or personal details.
